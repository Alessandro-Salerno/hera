# Hera VS Code Extension

Hera is an Entity-Relationship (ER) design language. This extension provides syntax highlighting and language configuration for Hera files (`.er`, `.hera`).

## Features

- **Syntax Highlighting**: Support for Hera keywords (`entity`, `relation`, `attribute`), modifiers (`total`, `exclusive`, `specifies`, `key`, `alias`), comments, strings, and numeric constants.
- **Language Configuration**: Automatic closing of brackets and quotes, and comment toggling.

## Usage

Simply open any `.er` or `.hera` file in VS Code to see Hera syntax highlighting in action.
